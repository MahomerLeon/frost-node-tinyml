# Processed data

Files in this folder are **generated by scripts**. Do not edit them by hand:
change the script and run it again.

The versions of the own dataset (`v1/`, `v2/`, ...) will also live here, built
from the captures in `data/raw/node/`. None exists yet.

## `ideam_uptc_hourly.csv`

Clean hourly table of the IDEAM station UPTC Tunja (public support data).

- Created by: `py ml/clean_ideam_data.py`
- Input: the three raw files in `data/raw/public/` (they are never modified)
- Rows: 41 902 (one per hour), from 2019-03-05 22:00 to 2026-11-03 23:00

| Column | Meaning | Unit |
|---|---|---|
| `timestamp` | time of the observation, as written by IDEAM | see note |
| `temperature_c` | air temperature at 2 m | °C |
| `humidity_pct` | relative humidity of the air | % |
| `pressure_hpa` | atmospheric pressure | hPa |

Cleaning steps:

1. Duplicated timestamps removed (3 482 in each raw file; duplicated rows
   always had the same value).
2. The three variables joined by timestamp.
3. Only hours with the three variables kept (692 incomplete hours dropped).

What was NOT done:

- Gaps were not filled and nothing was interpolated, so the table is **not
  continuous** (about 63 % of the hours of the period are present). Code that
  uses consecutive readings must check that the timestamps are really
  consecutive.
- No values were removed as outliers; all values are inside plausible ranges
  (see the audit in `data/raw/public/README.md`).

Note on time zone: the timestamps look like Colombian local time (UTC-5), not
UTC, because the coldest hour is 06:00 on average. This has not been verified
with IDEAM.
